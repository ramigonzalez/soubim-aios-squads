## Description

The repository had no CI: PRs were merged on local test runs only. Add GitHub Actions checks on every PR and push to `main`, and make them green from day one.

## Acceptance Criteria

- [x] `.github/workflows/ci.yml` — **Backend tests** job: Python 3.13, PostgreSQL with pgvector as a service, `pytest tests` against throwaway databases (Story 7.18), dummy secrets (tests never call the Claude API)
- [x] **Frontend** job: Node 22, `npm ci`, typecheck, lint, Vitest, Vite build
- [x] Backend: the 67 tests already failing on `main` (45 failed + 22 errors) listed in `decision-log-backend/tests/known_failures.txt` and deselected — any *new* failure turns CI red; fixing one means deleting its line
- [x] Frontend made fully green: 12 `SourceGroupAccordion` tests (missing mutation-hook mock) and 5 type errors (`FilterBar` unused vars, optional `projectId` in `useStages`/`useMilestones` — the hooks already skip the request without one, `SharedMilestoneTimeline` discipline type)
- [x] `requirements.txt` gains `psycopg2-binary` and `email-validator` — used by the app but missing (the cause of the broken backend Docker image noted in 13.8)

## Dev Notes

- Known failures are mostly old tests that create `ProjectItem` without the V2-required `statement`, and V1/V2 schema drift — a follow-up should fix them and empty the list.
- No branch protection yet: making the two checks required on `main` is a repository setting (follow-up, @devops).
