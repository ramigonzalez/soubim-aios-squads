# Story 13.5 — Manual Upload: .mp4 and .txt

**Story ID:** 13.5
**Epic:** E13 — Recording Ingestion
**Priority:** High | **Effort:** 5 SP (estimate)

**Type:** Feature
**Requested by:** Rami — "provide a way to import recordings .mp4 manually … also .txt files"

---

## Description

Meetings outside Fathom (Teams, in-person, phone, other recorders) are uploaded by hand: a **video** (.mp4) and/or a **transcript** (.txt). Large videos go **directly from the browser to storage** (pre-signed multipart), never through the API server.

## Acceptance Criteria (draft)

- [ ] "Adicionar reunião" form: project, title, date, visibility, participants; video file and/or transcript file
- [ ] Video: pre-signed multipart upload to storage (13.1) with progress and resume; size limit from settings; content-type check
- [ ] Transcript .txt: Fathom format (`M:SS - Name` + indented speech) parsed as today (`lib/transcript.ts`); **plain-text mode** for text without timestamps — viewer shows the text without turn links, items have no timestamp links
- [ ] Creates a pending Source in Ingestão; extraction via 13.6
- [ ] Supersedes the manual-paste idea of Story 7.8 (Draft) — reference it and close it as replaced

## Dev Notes

- **Proven by spike:** 761 MB multipart upload to S3-compatible storage + playback with seeking.
- Uploaded video without transcript: wait for E14 transcription, or upload a transcript too (decision per meeting).
- `.txt` encodings: accept UTF-8; detect and convert Latin-1 (common in Brazilian Windows exports).
