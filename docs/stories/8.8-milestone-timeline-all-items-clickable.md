# Story 8.8 — Milestone Timeline All Items Clickable (Investigation)

**Epic:** 8 (Milestone Timeline)
**Priority:** Low | **Effort:** 1 SP (~15 min)
**Status:** Done (Verified via Playwright)
**Type:** Investigation/Data fix

## Description
User reports only action items are clickable in the milestone timeline. Code analysis shows ALL `MilestoneNode` components receive `onClick` — no type-based filtering. Hypothesis: only action items may be marked `is_milestone=true` in the test data.

## Investigation Results

**Root cause was Story 9.7.** The `selectedDecision` in `ProjectDetail.tsx` was stored as a full object snapshot. When a milestone was clicked, the snapshot didn't stay in sync with React Query's data. The Story 9.7 fix (ID-based derivation via `useMemo`) resolved this for ALL item types.

**DB has milestones across all types:**
```
action_item: 1, decision: 6, idea: 1, information: 2, topic: 1
```

**Playwright verification (automated):** Clicked all 5 types (Info, Idea, Topic, Action, Decision) from the MilestoneTimeline — DrilldownModal opened correctly for every type.
