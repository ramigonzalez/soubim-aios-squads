# Story 12.1 — Organizations & Memberships

**Story ID:** 12.1
**Epic:** E12 — Organizations & Client Access
**Priority:** Critical | **Effort:** 5 SP (estimate)
**Status:** Draft
**Type:** Feature
**Requested by:** Rami — "each company is an org: souBIM and DIMAS are both organizations"

---

## Description

DecisionLog has no organization concept: `users.role` is global (`director`, `architect`, `client`), projects have members (`project_members`), and every director sees every project. Introduce **organizations** and **memberships** as the base of multi-company access. Every company is an organization (souBIM, DIMAS, future AEC firms); a user belongs to one or more organizations with a role in each.

**Out of scope:** authorization changes (12.2), project sharing (12.3), meeting visibility (12.4), invitations UI (12.5).

## Acceptance Criteria (draft)

- [ ] `organizations` table: id, name, slug, created_at (+ optional logo/locale later)
- [ ] `organization_members`: user_id, organization_id, role (`owner` / `admin` / `member`), created_at; unique (user, org)
- [ ] `projects.owner_organization_id` (FK) — the organization that created/owns the project
- [ ] Alembic migration with backfill: create "souBIM", make every existing user a member (current `director` → `admin`, others → `member`), set every existing project's owner to souBIM
- [ ] Models + Pydantic schemas; `GET /api/organizations/me` returns the user's organizations and roles
- [ ] Unit tests for the migration backfill and membership uniqueness

## Dev Notes

- Keep `users.role` during the transition; 12.2 moves checks to organization roles and then deprecates it.
- Client people (e.g. Débora at DIMAS) are members of **their own** organization (DIMAS), not guests in souBIM; access to souBIM projects comes from project sharing (12.3).
- A user can belong to several organizations (consultants, people changing companies) — the "active organization" is chosen in 12.5.
- Open decision (with Youval): is `owner/admin/member` enough, or do we need a `reviewer` role for 12.6?
