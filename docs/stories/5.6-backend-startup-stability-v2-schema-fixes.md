## Summary

Fix three interconnected post-migration issues that prevented the backend from starting correctly after the V2 data model evolution (Story 5.1). Missing ORM models caused import errors, V2 schema constraints were inverted (requiring V1 fields instead of V2), and the dev environment lacked PostgreSQL auto-start with SQLite fallback.

**Root cause:** The V2 migration (5.1) introduced new models and changed field semantics, but the ORM definitions, column constraints, and dev tooling weren't fully updated to match.
