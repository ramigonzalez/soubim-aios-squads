# Story 7.12 — Item Title, Transcript Excerpt and Meeting Summary

**Story ID:** 7.12 (includes the meeting summary, first planned as 7.14 — both need the same prompt revision and model re-run)
**Epic:** E7 — Multi-Source Ingestion Pipeline
**Priority:** High | **Effort:** 3 SP
**Status:** Ready for Review
**Type:** Feature
**Requested by:** Rami — feedback on the first real meeting (D/SEASON, 2026-09-04) in the UI

---

## Description

Reviewing the D/SEASON items in Project History showed three gaps:

1. **The whole statement is the title.** Rows and the modal header show 3–4 lines of text, so items are hard to scan.
2. **The Transcript tab is a placeholder** ("Meeting transcript and discussion notes would appear here") — there's no way to see what was actually said.
3. **There is no meeting summary.** The meeting header already has a summary toggle (Story 9.4, `MeetingSummary`), but `Source.ai_summary` was never filled for imported meetings and the items API didn't expose it.

**Out of scope:** recording link / opening the video at the timestamp (Story 7.13), Portuguese UI labels (Story 11.1), Similar tab (Story 7.15).

## Acceptance Criteria

### Extraction prompt (`extract_meeting.md`)
- [x] Each item has `title` — headline of at most 10 words, no final period
- [x] `statement` becomes the full 1–3 sentence description (does not repeat the title or paste the quote)
- [x] Each item has `source_excerpt` — 1–4 transcript turns copied verbatim as `M:SS - Speaker: text`, one per line, never translated
- [x] Top-level `meeting_summary` — 3–5 sentences (subjects, decisions, pending actions), in the transcript's language
- [x] Output example and Output Language rule updated

### Backend
- [x] `project_items.title` column (nullable, varchar 255) — Alembic `004_story_7_12`
- [x] `_validate_item` keeps `title` (trimmed, max 255) and `source_excerpt` for every item type
- [x] Import stores `title` and `source_excerpt`; `meeting_summary` is stored in `Source.ai_summary` (an existing summary is kept when the file has none)
- [x] `GET /api/projects/{id}/items` returns `title` and `source.summary`

### Frontend
- [x] Item rows show `title`, falling back to `statement`
- [x] Modal header shows `title`; Overview gets a **Description** card with the full statement when a title exists
- [x] Transcript tab lists the excerpt turns (time, speaker, text); "No transcript excerpt for this item." when there is none
- [x] Meeting header passes `source.summary` to the existing summary toggle
