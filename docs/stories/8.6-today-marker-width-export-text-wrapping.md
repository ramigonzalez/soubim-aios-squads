## Summary

Fix two visual issues in the Milestone Timeline: the "Today" marker dashed line spanned the full container width instead of starting at the vertical timeline line, and PDF/JPEG exports had ugly text line wrapping due to narrow rendering width. The Today marker now starts at the timeline center, and exports use wider rendering (1600px/1800px) with `whitespace-nowrap` to prevent wrapping.

**User impact:** The Today marker line extended into the stage label area (visually incorrect), and exported PDFs/JPEGs had broken text layout.

---

## Acceptance Criteria

### Today Marker Width
- [x] Today marker dashed line starts at the vertical timeline line position, not at container edge
- [x] Line extends from timeline center to the right edge of the container
- [x] No visual overflow into the stage label area on the left

### Export Text Wrapping
- [x] Export rendering uses wider canvas: 1600px for JPEG, 1800px for PDF
- [x] Milestone statement text uses `whitespace-nowrap` during export
- [x] No ugly mid-word line breaks in exported PDFs/JPEGs
- [x] Text truncation removed during export (full statement visible)
