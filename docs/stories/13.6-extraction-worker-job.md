# Story 13.6 — Extraction as a Worker Job

**Story ID:** 13.6
**Epic:** E13 — Recording Ingestion
**Priority:** High | **Effort:** 3 SP (estimate)
**Status:** Ready for Review
**Type:** Feature
**Requested by:** Rami — run "our process" from the app instead of scripts

---

## Description

Run meeting extraction (items + meeting summary, prompt `app/prompts/extract_meeting.md`) on the **Claude API** as an `extract` job in the worker (13.2), triggered when a meeting is approved in Ingestão. Today extraction was done outside the app (Claude Code CLI + `scripts/import_extracted_items.py`, Story 7.10) because the in-app pipeline is broken.

## Acceptance Criteria

- [x] Approving a meeting enqueues `extract`; the job renders the prompt (title, date, type, duration, roster with roles), calls the Claude API with structured output (the eval `schema.json`), stores items via `app/services/item_import.py` (keeps title, excerpt, why, consensus, impacts, timestamp) and `meeting_summary` → `Source.ai_summary`
- [x] Model id from settings; output limit sufficient for a 2-hour meeting
- [x] Failure → source `failed` with a readable `extraction_error`, retry from Ingestão
- [x] Cost per meeting logged (input/output tokens) and estimated cost displayed in the "Versões" panel

## Changes in This Task (13.6 Remainder)

**Scope:** Implement estimated cost display for extraction runs (13.7 Assumption #8).

**Backend (`app/config.py`):** Added `model_pricing` dictionary with USD pricing per million tokens for `claude-opus-5-5` and `claude-sonnet-5-5`. List prices from the Claude API docs (Opus 5.5 $4/$20, Sonnet 5.5 $2/$10 per MTok); estimate only (no cache/batch discounts); override with `MODEL_PRICING`.

**Backend (`app/api/routes/extraction_runs.py`):** Added `_calculate_extraction_cost()` helper to compute estimated cost from tokens and pricing table. Returns None if model or tokens missing. Included `estimated_cost_usd` in API response alongside `input_tokens` and `output_tokens`.

**Frontend (`ExtractionVersions.tsx`):** Display estimated cost alongside tokens in each version row, with format "$X.XXXX (estimated)".

**Frontend i18n:** Added `cost` key to both `en/meeting.json` and `pt-BR/meeting.json`.

**Frontend types (`useExtractionRuns.ts`):** Added `estimated_cost_usd: number | null` to `ExtractionRun` interface.
