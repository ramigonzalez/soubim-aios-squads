# Story 13.6 — Extraction as a Worker Job

**Story ID:** 13.6
**Epic:** E13 — Recording Ingestion
**Priority:** High | **Effort:** 3 SP (estimate)
**Status:** Draft
**Type:** Feature
**Requested by:** Rami — run "our process" from the app instead of scripts

---

## Description

Run meeting extraction (items + meeting summary, prompt `app/prompts/extract_meeting.md`) on the **Claude API** as an `extract` job in the worker (13.2), triggered when a meeting is approved in Ingestão. Today extraction was done outside the app (Claude Code CLI + `scripts/import_extracted_items.py`, Story 7.10) because the in-app pipeline is broken.

## Acceptance Criteria (draft)

- [ ] Approving a meeting enqueues `extract`; the job renders the prompt (title, date, type, duration, roster with roles), calls the Claude API with structured output (the eval `schema.json`), stores items via `app/services/item_import.py` (keeps title, excerpt, why, consensus, impacts, timestamp) and `meeting_summary` → `Source.ai_summary`
- [ ] Model id from settings; output limit sufficient for a 2-hour meeting
- [ ] Failure → source `failed` with a readable `extraction_error`, retry from Ingestão
- [ ] Cost per meeting logged (input/output tokens)
