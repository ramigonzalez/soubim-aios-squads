# Story 9.7 — DrilldownModal Stale State on Toggle Done

**Epic:** 9 (Project History)
**Priority:** Highest | **Effort:** 1 SP (~0.25 days)
**Status:** Done
**Type:** Bug Fix

## Description
Clicking "Mark as done" in the DrilldownModal doesn't update the modal UI until page reload. The timeline row updates correctly but the open modal shows stale data.

**Root Cause:** `ProjectDetail.tsx` stores `selectedDecision` as a full `ProjectItem` object snapshot in React state. When `useToggleDone` fires its optimistic update, React Query refreshes the `decisions` array, but the `selectedDecision` state variable remains a stale copy captured at click time.

## Acceptance Criteria
- [x] DrilldownModal checkbox reflects `is_done` change immediately after toggling (no reload needed)
- [x] Milestone star toggle in modal also reflects changes immediately
- [x] Closing and reopening modal on same item shows latest state
- [x] No regressions in timeline row toggle behavior
