## Description

After transcription (14.1), a reviewer listens to each detected voice and names it. The transcript is rebuilt with real names, uncertain turns flagged with ⚠️, then extraction runs (13.6).

## Acceptance Criteria (draft)

- [ ] Screen per meeting: one card per detected voice with 3 audio clips (play), talk time, and hints (overlap with Fathom's per-mic labels, as `map_speakers.py` does)
- [ ] Assign a project participant, or mark "mixed" with the possible people (e.g. Camila / Erica), or "unknown"
- [ ] Optional rule "person X only present from time T" (D/SEASON: Erica joined at 0:50)
- [ ] "Gerar transcrição": rebuild turns with names and ⚠️ reasons (mixed voices, overlapping speech, voiceprint suggests X) — port of `relabel.py` + `write_transcript.py`; store as the meeting transcript
- [ ] Then enqueue extraction (13.6)

## Dev Notes

- Pilot effort: ~5 minutes of listening per 98-min meeting.
- Room-microphone participants are configured per meeting (currently hardcoded `ROOM = {...}` in `relabel.py`).
- Labels in pt-BR (i18n namespaces).
