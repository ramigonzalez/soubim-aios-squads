# Story 12.5 — Users, Invitations & Active Organization

**Story ID:** 12.5
**Epic:** E12 — Organizations & Client Access
**Priority:** High | **Effort:** 5 SP (estimate)
**Status:** Draft
**Type:** Feature
**Requested by:** Rami — grant clients access through the app

---

## Description

Organization admins invite people by email; invitees create their account (or log in) and join the organization. Users in more than one organization switch the **active organization** in the navigation; everything they see is scoped to it (12.2).

## Acceptance Criteria (draft)

- [ ] `organization_invitations`: email, organization, role, token (hashed), expires_at, accepted_at
- [ ] Admin UI: invite by email with role, list pending invitations, revoke
- [ ] Accept flow: invitation link → set password (new user) or log in (existing) → membership created
- [ ] Inviting a company that has no organization yet: create the organization on acceptance, invitee becomes its `owner`
- [ ] Organization switcher in Navigation; active organization stored per session and sent with API calls
- [ ] Email sending via a provider (open decision); in dev, invitation link printed in the backend log
