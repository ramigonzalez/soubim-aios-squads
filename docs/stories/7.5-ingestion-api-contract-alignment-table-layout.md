## Summary

Align the backend ingestion API response shape with the frontend TypeScript contract, add missing router registrations, and improve the Ingestion Approval page table layout. The backend responses didn't match the frontend types, causing runtime errors. The table layout lacked fixed columns, overflow handling, and proper resize behavior.

**User impact:** Ingestion Approval page was non-functional due to API contract mismatches, and the table layout had text overflow and poor column sizing.

---

## Acceptance Criteria

### Backend API Alignment
- [x] Ingestion response shape matches frontend `IngestionSource` TypeScript type
- [x] `included` toggle field added to Source model and API responses
- [x] `pending_count` added to list endpoint response
- [x] `source_label` column added to Source model
- [x] Missing routers registered in `main.py` (ingestion, project_items, stages, participants)
- [x] 7 pending sources seeded for Ingestion Approval page testing

### Frontend Table Layout
- [x] `table-fixed` layout with explicit column widths
- [x] Resize handles on table columns
- [x] `truncate` + `title` tooltips on overflow cells
- [x] `title` column added to `MeetingSourceRow`
- [x] Consistent row styling across `MeetingSourceRow`, `EmailSourceRow`, `DocumentSourceRow`
