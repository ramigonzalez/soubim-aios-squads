# Story 6.5 — ProjectForm Stage & Participant Integration

**Epic:** 6 (Project Management)
**Priority:** High | **Effort:** 5 SP (~1.5 days)
**Status:** Done
**Type:** Feature (completes Story 6.2)

## Description
`ProjectForm.tsx` only has basic fields (name, description, type, drive_folder_id). `StageScheduleBuilder` and `ParticipantRoster` components exist as orphaned components but aren't wired into the form. Users can't create stages or add participants when creating/editing projects.
