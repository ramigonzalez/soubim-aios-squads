# Story 12.3 — Project Sharing Between Organizations

**Story ID:** 12.3
**Epic:** E12 — Organizations & Client Access
**Priority:** High | **Effort:** 5 SP (estimate)
**Status:** Draft
**Type:** Feature
**Requested by:** Rami — "projects are shared between orgs"

---

## Description

A project like D/SEASON involves souBIM (architecture) and DIMAS (construtora). The owning organization can **share a project with another organization** at an access level. Members of the invited organization then see the project and its **shared** meetings (12.4).

## Acceptance Criteria (draft)

- [ ] `project_organizations`: project_id, organization_id, access (`owner` / `contributor` / `viewer`), invited_by, created_at; the owner org has an `owner` row
- [ ] Owner-org admins can invite an organization to a project, change its access, remove it
- [ ] `contributor` can add meetings/items to the project; `viewer` only reads
- [ ] Project Edit page: "Organizações com acesso" section (list, invite, change, remove)
- [ ] Removing an organization immediately removes its access (covered by 12.2 isolation tests)

## Dev Notes

- Invitation target: an existing organization (by name/slug) for now; inviting a company that has no account yet goes through 12.5 invitations.
- `project_participants` (discipline roster) stays as is — it describes who attends meetings, not who has app access. Consider linking a participant to a user later.
- Open decision: can an invited organization re-share the project with a third one? (Proposal: no — only the owner org.)
