# Story 7.6 — Ingestion Include Default Fix

**Epic:** 7 (Ingestion Pipeline)
**Priority:** Highest | **Effort:** ~0.5 day

## Description
New sources default to `included=True`, meaning they're automatically included for processing. This should be `False` — admins should explicitly include sources during review.

- [x] API fallback for null `included` returns `False`

- [x] No source creation code explicitly sets `included=True` (except seed data)
