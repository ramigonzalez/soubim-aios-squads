# Story 9.6 — Action Items UI Enhancement

**Epic:** 9 (Project History)
**Priority:** Medium | **Effort:** ~1.5 days
**Status:** Done

## Description
Action items render identically to decisions/topics/ideas. The `useToggleDone` hook exists but is never used. `owner` and `is_done` are in the model but not displayed. `due_date` was missing from the database model.

## Acceptance Criteria
- [x] `due_date` column added to ProjectItem model
- [x] `due_date` included in API responses
- [x] ProjectItemRow shows checkbox, owner badge, due date for action items
- [x] Checkbox toggles `is_done` via useToggleDone (with optimistic update)
- [x] Strikethrough styling when `is_done === true`
- [x] Overdue indicator (red) when due date is past and not done
- [x] DrilldownModal shows action item details section
