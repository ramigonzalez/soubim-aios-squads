## Summary

Fix three visual alignment bugs in the Milestone Timeline (Story 8.1): the vertical connector line was not responsive and misaligned from stage dots by up to 48px on desktop, milestone item dots were disconnected from the vertical line due to wrong offset and reversed connector order, and the "Today" marker broke on page refresh because it lacked a ResizeObserver for async content changes.

**User impact:** Gabriela sees a broken timeline where the vertical line, stage dots, milestone dots, and Today marker are all visually disconnected — undermining the "60-second project understanding" goal.

## Root Cause Analysis

### Bug 1: Vertical line not responsive
The vertical line was hardcoded at `left: calc(9rem + 10px)` but the stage dot center is at `label_width + gap + half_dot`:
- Mobile: `9rem + 1rem + 10px` = `calc(10rem + 10px)` — off by **16px**
- Desktop: `11rem + 1rem + 10px` = `calc(12rem + 10px)` — off by **48px**

The `1rem` gap (`gap-4` in StageNode flex layout) was never accounted for, and no `lg:` responsive variant existed.

### Bug 2: Milestone dots disconnected
Two problems:
1. Connector rendered `[line][dot]` left-to-right, placing the dot to the **right** of the vertical line center instead of on it
2. Offset `-left-[2.75rem]` positioned the dot center at `~10.375rem` instead of the vertical line center at `~10.625rem` (4px off)

### Bug 3: Today marker breaks on refresh
`useTodayPixelPosition` only recomputed on mount and `window.resize`. When milestones loaded asynchronously (React Query fetch), the DOM sections expanded but the hook didn't recalculate — leaving the Today marker at a stale position computed from empty/minimal DOM.

## Dev Notes

### Alignment Math (for future reference)

All elements must align on the **timeline center X**:

| Breakpoint | Label | Gap | Half-dot | Timeline Center X |
|------------|-------|-----|----------|-------------------|
| Mobile (`<1024px`) | `9rem` (`w-36`) | `1rem` (`gap-4`) | `10px` (half of `20px`) | `calc(10rem + 10px)` = 170px |
| Desktop (`≥1024px`) | `11rem` (`lg:w-44`) | `1rem` (`gap-4`) | `10px` (half of `20px`) | `calc(12rem + 10px)` = 202px |

**Milestone connector geometry** (at 16px base font):
- Dot: `w-3` = 12px, center at 6px from dot left edge
- Line: `w-4` = 16px
- Total connector: 28px = 1.75rem
- Offset: `-left-[1.75rem]` from content edge
- Content margin: `12rem` (mobile) / `14rem` (desktop)

### ResizeObserver pattern
```typescript
useEffect(() => {
  compute()
  window.addEventListener('resize', compute)

  let ro: ResizeObserver | undefined
  if (containerEl) {
    ro = new ResizeObserver(compute)
    ro.observe(containerEl)
  }

  return () => {
    window.removeEventListener('resize', compute)
    ro?.disconnect()
  }
}, [compute])
```

No infinite loop because: TodayMarker is `position: absolute` → changing its `top` doesn't affect container layout → ResizeObserver doesn't re-fire.
