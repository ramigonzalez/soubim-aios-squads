# Story 7.7 — Source Curation Workflow

**Epic:** 7 (Ingestion Pipeline)
**Priority:** Lower | **Effort:** ~3 days
**Status:** Done

## Description
Sources go directly into the ingestion pipeline with no human curation step. This story adds:
1. Auto-upload source content to Google Drive for human review
2. Scheduled sync to pull curated content back into the system

## Acceptance Criteria
- [x] DriveClient has upload_file() and get_file_metadata() methods
- [x] Source model has curation_status and last_synced_at fields
- [x] SourceCurationService handles upload, sync check, and batch poll
- [x] Source creation hooks trigger auto-upload (webhook, gmail, drive)
- [x] Scheduler runs daily curation sync (configurable)
- [x] Manual trigger API endpoints for upload and sync
- [x] Storage backend abstraction for future S3 support

## Configuration
```env
CURATION_SYNC_ENABLED=true
CURATION_SYNC_INTERVAL_HOURS=24
```

## Considerations
- Drive scope expansion requires updating Google Cloud Console service account permissions
- StorageBackend abstract class enables future S3/other backends
- Race condition guard: only sync if file unchanged for 5+ minutes
