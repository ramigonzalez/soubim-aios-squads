## Story

As an **admin inviting someone**, I want the invitation to arrive by email, so that people can join without me copying links from a log.

## Context (current behaviour, verified)

- `app/services/email_sender.py` has an `EmailSender` interface and only a **dev log sender**: in dev the email body (with the invitation link) is written to the log; otherwise a warning says nothing was sent.
- Invitations (`app/services/invitations.py`, 12.5) call `get_email_sender().send(to, subject, body)`.
- No production provider exists, so invitations can't be delivered in production.

## Acceptance Criteria (draft)

- [ ] `ResendEmailSender` posts to the Resend API (`POST https://api.resend.com/emails`) with an API key. Use the official `resend` Python package or plain `httpx`, following the existing integrations style.
- [ ] Settings: `EMAIL_PROVIDER` = `log` | `resend` (default `log`), `RESEND_API_KEY`, `EMAIL_FROM` (e.g. `DecisionLog <no-reply@send.codeshift.space>`). Startup warns, and does not crash, when `resend` is chosen without a key.
- [ ] `send()` returns False and logs the error (never the key) on a 4xx/5xx or timeout. The invitation still exists, and the admin can copy the link from the UI (12.5) as a fallback.
- [ ] Plain-text body as today; an HTML version is phase 2.
- [ ] Tests with a fake HTTP transport: success, API error, timeout, missing key.
- [ ] Docs: `.env.development.example`, `DEPLOYMENT_RAILWAY.md` (API and worker variables), and the DNS steps below.

## Setup (Rami, in Resend and DNS)

1. Resend → **Domains → Add** `send.codeshift.space`. A subdomain keeps the main domain's reputation separate.
2. Add the DNS records Resend shows at the DNS host of `codeshift.space`:
   - the MX and SPF TXT records on `send`;
   - the DKIM TXT record;
   - recommended: a DMARC TXT record `_dmarc` with `v=DMARC1; p=none;`.
3. Click **Verify**, then create an API key with **Sending access** for that domain only.
4. Put `RESEND_API_KEY` in Railway (API + worker) and `.env.development`. Never commit it and never paste it in chat.

## Out of scope (phase 2)

- HTML templates and branding.
- Other emails (password reset, notifications, digests).
- Bounce and complaint webhooks.
