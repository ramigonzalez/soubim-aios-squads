# Story 13.2 — Background Worker & Jobs Table

**Story ID:** 13.2
**Epic:** E13 — Recording Ingestion
**Priority:** High | **Effort:** 8 SP (estimate)
**Status:** Draft
**Type:** Feature (infrastructure)
**Requested by:** Rami — design the background worker

---

## Description

Slow steps (downloading a recording, extraction, later GPU transcription) run today inside the web process via FastAPI `BackgroundTasks` (`app/services/ingestion_pipeline.py`) — lost on restart, no retries, no status. Add a **jobs table in Postgres** and a **worker process** (same codebase, different start command) that picks jobs with `SELECT … FOR UPDATE SKIP LOCKED`. No Redis or extra service.

## Acceptance Criteria (draft)

- [ ] `jobs` table: id, type, payload (JSON), status (`queued` / `running` / `succeeded` / `failed`), attempts, max_attempts, run_after, locked_by, locked_at, last_error, source_id, organization_id, timestamps
- [ ] Worker loop: claim one job with `FOR UPDATE SKIP LOCKED`, run its handler, retry with backoff, mark failed after max attempts; stale-lock recovery
- [ ] Handlers registry; first handlers: `fathom_import` (13.4), `extract` (13.6); stubs for `transcribe` (14.1)
- [ ] Meeting (Source) shows job status in Ingestão (e.g. "Baixando gravação", "Extraindo", "Falhou — tentar novamente")
- [ ] Start command `python -m app.worker`; `docker-compose` service for local dev; graceful shutdown
- [ ] Tests: concurrent workers never run the same job; retries; failure surfaces on the source

## Dev Notes

```
Web API ──insert──▶ jobs (Postgres) ──claim (SKIP LOCKED)──▶ worker
                                                     ├─ fathom_import → storage (13.1)
                                                     ├─ transcribe    → GPU (14.1)
                                                     └─ extract       → Claude API (13.6)
```
- Replaces `BackgroundTasks` for ingestion; the existing state machine (`pending → approved → processed/failed`, Story 7.9) stays.
- Railway: the worker is a second service from the same repo (13.8).
